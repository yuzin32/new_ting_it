## 📝 프로젝트 소개

**건강한 식탁(Thing It)** 은 질병별 건강 정보와 관련 식재료를 확인할 수 있는 웹 서비스입니다.

질병에 따른 식재료 정보를 쉽게 탐색할 수 있도록 구성했으며, 복수의 질병을 선택하면 각 질병의 추천 식재료를 비교하고 공통 항목을 확인할 수 있도록 개발하고 있습니다.

- **프로젝트명:** 건강한 식탁 (Thing It)
- **개발 유형:** 개인 웹 프로젝트
- **주요 분야:** 건강 정보 및 식재료 추천
- **개발 목적:** Spring Boot 기반 백엔드 개발 및 데이터베이스 연동 역량 강화

## 🎯 개발 목적

- 질병별 건강 정보와 식재료 정보를 체계적으로 제공
- 선택한 질병을 기반으로 맞춤형 식재료 추천 기능 구현
- 여러 질병에 해당하는 공통 식재료를 비교할 수 있도록 데이터 처리
- Spring Boot REST API 개발 및 데이터베이스 연동 경험 확보

## 🛠️ 기술 스택

## ✨ 주요 기능

### 1. 질병 정보 조회

- 질병 카테고리별 정보 조회
- 질병 및 관련 부위 검색
- 카테고리에 따른 질병 데이터 제공

### 2. 맞춤 식재료 추천

- 사용자가 원하는 질병 선택
- 선택한 질병 ID를 백엔드 API로 전달
- 데이터베이스에서 관련 식재료 조회
- 조회 결과를 화면에 표시

### 3. 복수 질병 식재료 비교

- 여러 질병을 동시에 선택
- 질병별 추천 식재료 비교
- 식재료 ID를 기준으로 중복 데이터 처리
- 복수 질병에서 공통으로 추천되는 식재료 구분

## 🔌 API 명세

| Method | Endpoint | 설명 |
|:---:|:---|:---|
| `GET` | `/api/diseases/{category}` | 카테고리별 질병 정보 조회 |
| `POST` | `/api/foods/recommend` | 선택한 질병에 따른 식재료 추천 |

### 식재료 추천 API 요청 예시

**Request**

```http
POST /api/foods/recommend
Content-Type: application/json
```

```json
{
  "diseaseIds": [23, 24]
}
```

**설명**

- `diseaseIds`: 추천 대상 질병의 ID 목록
- 응답 데이터: 실제 API에서 반환하도록 구현한 식재료 정보

※ 요청 형식과 응답 구조는 실제 컨트롤러 및 DTO 구현에 맞게 수정합니다.

- Spring Boot 기반 REST API 설계 및 요청 데이터 처리
- JdbcTemplate을 활용한 SQL 작성과 데이터베이스 조회
- 프론트엔드와 백엔드 간 HTTP 요청 및 응답 처리
- 복수 질병에 해당하는 식재료의 중복 데이터 처리

## 🚀 실행 방법

### 1. 프로젝트 클론

```bash
git clone <YOUR_REPOSITORY_URL>
cd <YOUR_PROJECT_DIRECTORY>
```

### 2. 개발 환경 준비

- Java 17
- Gradle
- MySQL

### 3. 데이터베이스 설정

MySQL 데이터베이스를 준비하고 프로젝트의 데이터베이스 연결 설정을 구성합니다.

### 4. 애플리케이션 실행

Windows 환경에서는 다음 명령어로 실행할 수 있습니다.

```bash
gradlew.bat bootRun
```

또는 IntelliJ IDEA에서 Spring Boot 메인 클래스를 실행합니다.

※ 데이터베이스 테이블과 초기 데이터가 준비되어 있어야 정상적으로 실행됩니다.
